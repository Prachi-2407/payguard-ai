🚀 How to Load & Test in Chrome:

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable Developer mode (toggle in top-right corner).
  3. Click Load unpacked and select the extension directory in this repo.
  4. Ensure the extras service is running on http://localhost:8001 (and optionally backend on 8000).
  5. Open this file in Chrome (e.g. file:///.../extension/test_page/index.html).
  6. Observe the colored risk badges injected beside each link, or click the extension popup icon in the toolbar.
